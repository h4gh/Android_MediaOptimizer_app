# Media Optimizer

Android app that shrinks photos and videos for sending (e-mail, messengers).

- Specs: [docs/PRD.md](docs/PRD.md), [docs/TECH_DESIGN.md](docs/TECH_DESIGN.md)
- Stack: Kotlin, Jetpack Compose, Media3 Transformer. Min Android 10.
- Fonts: Sora and DM Sans (SIL Open Font License), bundled in `app/src/main/res/font`.

## Test builds

Every push builds a debug APK with GitHub Actions and publishes it under
[Releases](../../releases/latest). Open that page on the phone, download the
APK and install it.
